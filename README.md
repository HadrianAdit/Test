# Hadrian Aditia — Premium Developer Portfolio

Portfolio personal premium, original, responsive untuk HP dan desktop.

## File
- `index.html` — isi dan struktur website
- `style.css` — desain, animasi, responsive layout
- `script.js` — animasi reveal saat scroll

## Edit
Buka `index.html`, lalu ubah:
- Nama / deskripsi
- Project
- Link Instagram, WhatsApp, GitHub

## Jalankan
Klik dua kali `index.html` untuk membukanya di browser.

## Vercel
Upload folder ini ke GitHub lalu import repository ke Vercel.
